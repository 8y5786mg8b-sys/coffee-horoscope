# Coffee Horoscope

生年月日と出生国（首都基準）から、今日のコーヒーホロスコープを表示する静的Webアプリです。

## Vercelで公開する

1. このフォルダ一式をGitHubの `coffee-horoscope` リポジトリへアップロードします。
2. Vercelで **Add New → Project** を開きます。
3. `coffee-horoscope` をImportします。
4. Framework Presetは **Other** のまま、Deployします。

## GitHub Pagesで公開する

1. このフォルダ一式をリポジトリの `main` ブランチへ入れます。
2. GitHubで **Settings → Pages** を開きます。
3. Sourceを **GitHub Actions** にします。
4. Actionsが完了すると公開URLが発行されます。
